Proyecto de mecatrónica y automatización

Mesa roto-basculante integrada con ABB

Desarrollo de un posicionador robótico roto-basculante de dos grados de libertad permite reorientar piezas durante impresión 3D, para limitar la generación de soportes. Se integra con un robot industrial ABB IRB 2600 mediante comunicación TCP/IP.

Problema

En impresión 3D por deposición de material, las geometrías con voladizos pronunciados suelen requerir estructuras de soporte. Estas aumentan el tiempo de impresión, el consumo de material y el trabajo de posprocesado, además de poder afectar el acabado superficial de la pieza.

El proyecto abordó esta limitación mediante la reorientación controlada de la pieza durante el proceso de fabricación, con el objetivo de mantener ángulos de deposición más favorables y reducir la dependencia de soportes.

Solución

Se desarrolló una mesa roto-basculante de dos grados de libertad capaz de modificar la orientación de la superficie de impresión mediante un eje de inclinación y un eje de rotación. El sistema fue concebido como un posicionador complementario para trabajar junto con un robot industrial ABB IRB 2600.

La solución integró diseño mecánico, transmisiones por banda síncrona, motores paso a paso, control embebido con Arduino Mega, regulación de una cama calefactada y comunicación Ethernet mediante TCP/IP con el controlador ABB IRC5.

Mi contribución

Diseñé e implementé la solución de manera integral, abarcando el desarrollo mecánico, la electrónica de potencia y control, la programación del firmware y la integración de comunicación con el robot industrial.

Mi trabajo incluyó el modelado CAD del mecanismo, la selección de transmisiones, la simulación dinámica de requerimientos de torque, el desarrollo del protocolo de comandos entre ABB y Arduino, la lógica de movimiento de los ejes, el control térmico de la cama y la validación experimental del prototipo.

Proceso

El proyecto inició con el análisis del problema de reorientación de piezas en impresión 3D y la definición de una arquitectura de dos grados de libertad. A partir de ello, se diseñó el mecanismo en Autodesk Inventor y se evaluó su comportamiento mediante simulación dinámica para estimar requerimientos de torque y validar la viabilidad del sistema.

Posteriormente se construyó el prototipo físico, incorporando motores paso a paso, drivers TB6600, una cama calefactada, sensores de referencia y una caja de control. Se programó un Arduino Mega para gestionar movimiento, homing, calibración y temperatura.

Finalmente, se implementó la comunicación TCP/IP con el controlador ABB IRC5, permitiendo enviar comandos de orientación, consultar estados del sistema y coordinar la operación de la mesa con una interfaz desarrollada en RobotStudio y FlexPendant.

Resultados

El prototipo logró ejecutar movimientos controlados de inclinación y rotación, responder a comandos enviados desde el entorno ABB y operar con una cama calefactada en el rango requerido para pruebas de impresión.

En la validación experimental se realizaron pruebas de posicionamiento a distintos ángulos, obteniendo una precisión aproximada de 0,05 y una repetibilidad cercana a 0,039, valores considerados adecuados para tareas de reorientación durante el proceso de deposición.

El proyecto demostró la factibilidad de integrar un posicionador mecatrónico con un robot industrial para explorar estrategias de impresión 3D con menor dependencia de soportes y mayor flexibilidad de orientación.
