F1TENTH / RoboRacer Ecuador

Integración y programación de un vehículo autónomo de carreras a escala 1:10, basado en la plataforma F1TENTH. El sistema combinó percepción con LiDAR, localización, planificación de ruta y control de trayectoria para competir de forma autónoma en circuitos cerrados.

ROS2 F1TENTH LiDAR Hokuyo SLAM AMCL Pure Pursuit f1tenth_gym

Área Robótica móvil y conducción autónoma
Plataforma Vehículo F1TENTH escala 1:10 con ROS2
Resultado 1.º lugar en RoboRacer Ecuador

Problema

Un vehículo autónomo de carreras debe percibir el entorno, localizarse, planificar una trayectoria y ejecutar control de dirección en tiempo real, manteniendo estabilidad y evitando colisiones dentro de una pista cerrada.

Solución

Se desarrolló un pipeline de navegación en ROS2 basado principalmente en LiDAR, utilizando SLAM para mapeo, AMCL para localización y Pure Pursuit para seguimiento de trayectoria, validando el sistema primero en simulación y luego en el vehículo real.

Mi contribución

Generación de mapas de ocupación 2D del circuito mediante slam_toolbox.
Procesamiento de escaneos del LiDAR Hokuyo para representar la pista.
Apoyo en la definición de waypoints y trayectoria ideal sobre el mapa.
Uso de algoritmos de búsqueda de caminos para planificar rutas eficientes.
Integración y pruebas del algoritmo Pure Pursuit en f1tenth_gym.
Ajuste de parámetros de velocidad, lookahead y estabilidad de seguimiento.
Validación física del sistema de navegación autónoma en la pista real.

Arquitectura técnica

Percepción con LiDAR

El vehículo utilizó un LiDAR Hokuyo como sensor principal para obtener información del entorno y detectar los límites del circuito.

Mapeo del circuito

Se generaron mapas de ocupación 2D mediante SLAM, permitiendo construir una representación digital de la pista para navegación autónoma.

Localización y ruta

Se empleó AMCL para estimar la posición del vehículo sobre el mapa, junto con una ruta definida mediante waypoints y planificación de trayectoria.

Control de trayectoria

El seguimiento de ruta se realizó con Pure Pursuit, ajustando parámetros de lookahead y velocidad para equilibrar rapidez, estabilidad y seguridad.

Proceso de desarrollo

01

Simulación inicial

Se implementó y probó la lógica de navegación en f1tenth_gym para validar el comportamiento del vehículo antes de transferir el código al hardware real.

02

Mapeo del circuito

Se realizaron pruebas con el LiDAR Hokuyo para generar mapas de ocupación del entorno real usando herramientas de SLAM en ROS2.

03

Planificación de trayectoria

Se definieron waypoints y rutas sobre el mapa, buscando una trayectoria eficiente para completar el circuito de forma rápida y segura.

04

Ajuste del controlador

Se calibraron parámetros de Pure Pursuit, incluyendo velocidad y lookahead, para mejorar el seguimiento de trayectoria y reducir riesgo de colisiones.

05

Pruebas físicas y competencia

Se transfirió el sistema al vehículo real, se realizaron pruebas en pista y se ajustó el comportamiento del auto para maximizar estabilidad y desempeño.
